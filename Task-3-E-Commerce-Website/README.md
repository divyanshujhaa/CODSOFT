# LUXE. - Premium Sneaker Store UI

## Overview

**LUXE.** is a premium luxury sneaker shopping mobile application designed in **Figma** as part of my **UI/UX Design Internship at CodSoft**.

The application focuses on delivering a modern, elegant, and seamless shopping experience with a premium dark theme, intuitive navigation, and luxury branding.


## Features

- Premium splash screen
- Modern home page
- Product details screen
- Shopping cart & checkout
- Interactive prototype
- Luxury dark-themed interface
- Responsive mobile-first design

- Splash Screen

- Product Details
- Shopping Cart
