# Midnight Cravings - Restaurant Menu UI

## Overview

Midnight Cravings is a modern restaurant menu and food ordering mobile application designed in Figma as part of my UI/UX Design Internship at CodSoft.

The application focuses on delivering a clean, visually appealing, and user-friendly food ordering experience with a premium dark theme.


## Features

* Modern splash screen
* Interactive home menu
* Food details page
* Shopping cart & bill summary
* Smooth navigation prototype
* Dark premium UI with orange accents


## Tools Used

* Figma


## Screens Included

* Cover Screen
* Menu
* Food Details
* Cart 


## Design Highlights

* Minimal and modern interface
* Consistent visual hierarchy
* User-friendly navigation
* Interactive prototype
* Mobile-first design
